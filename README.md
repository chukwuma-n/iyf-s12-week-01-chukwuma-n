## Project Description

This project is my Week 1 Web Foundations project for the IYF Season 12 program.

I built a multi-page personal portfolio website to practice HTML5, semantic HTML, accessibility, CSS, browser DevTools, Git, and GitHub.

## Technologies Used

* HTML5
* CSS3
* Visual Studio Code
* Git
* GitHub
* Microsoft Edge DevTools

## Tasks Completed

### Task 1.2: DevTools Exploration

I used browser DevTools to inspect three websites and identify HTML elements, page structure, navigation, search elements, link hover styles, and form controls.

The answers and screenshot are documented in:

`devtools-exploration.md`

### Task 1.3: Multi-Page Portfolio Website

I created a multi-page portfolio website containing:

* Home page
* About page
* Projects page
* Contact page
* Consistent navigation across the pages
* Current-page navigation indicators
* Accessible contact form
* Portfolio image with alternative text

### Task 1.4: Semantic HTML Conversion

I converted a webpage structure to use semantic HTML elements including:

* `<header>`
* `<nav>`
* `<main>`
* `<article>`
* `<aside>`
* `<footer>`

The work is available in:

`semantic-conversion.html`

### Accessibility Audit

I used Lighthouse in Microsoft Edge DevTools to test the website.

The Accessibility score was:

**100/100**

The detailed audit is documented in:

`accessibility-report.md`

## How to Run

1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Use the Live Server extension to preview the website.
