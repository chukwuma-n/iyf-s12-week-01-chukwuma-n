Understanding Semantic HTML

Semantic HTML uses elements that describe the meaning and purpose of the content they contain. This makes webpages easier for people and assistive technologies to understand.

Common Semantic Elements

Poor HTML Semantic HTML
<div class="header"> <header>
<div class="nav"> <nav>
<div class="main"> <main>
<div class="article"> <article>
<div class="sidebar"> <aside>
<div class="footer"> <footer>
<div class="title"> <h1>
<div class="text"> <p>
Navigation items <ul> + <li>

Why Semantic HTML Matters

Semantic elements improve the structure of a webpage, support accessibility, and make the code easier for developers to understand and maintain.
